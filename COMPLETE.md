## ?? How to Use

### Clone and Run (1 minute)
```bash
git clone https://github.com/phlzas/task-api.git
cd task-api/tasks
dotnet run
```

### Test the API (2 minutes)
```bash
# Create a task
curl -X POST http://localhost:5241/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Learn SQLite"}'

# List tasks
curl http://localhost:5241/tasks

# Restart server - data still exists!
```
